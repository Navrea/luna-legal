# Luna — documents légaux

Pages légales publiques de l'application mobile **Luna** (suivi du cycle menstruel),
éditée par Alexis Barthou sous le nom **Navrea**.

Publiées via GitHub Pages :

- https://navrea.github.io/luna-legal/confidentialite.html
- https://navrea.github.io/luna-legal/cgu.html

Google Play exige une politique de confidentialité accessible sans connexion, hors de
l'application. Ces deux URLs sont également compilées dans l'app (`src/constants/app.ts`)
et déclarées sur la fiche du Play Store.

Contact : navrea.dev@gmail.com

> Ces fichiers sont une copie du dossier `legal/` du dépôt privé de l'application.
> Toute modification doit être faite là-bas puis reportée ici, pour que l'app et les
> pages publiées ne divergent pas.
